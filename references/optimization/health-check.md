## Strategy Health Check

**Purpose:** trend diagnosis, not a new platform threshold. LOW_2Y and IS Ladder remain the hard recent-performance checks when the platform returns them.

### Diagnose

- Compare recent yearly Sharpe/Returns with the earlier history using platform evidence.
- Repeated deterioration is a **weakening hypothesis**, not automatic failure.
- Stable/improving recent behavior supports continued investment but does not bypass evidence relevant to the active defect or the requirement to use fresh candidate evidence before promotion.

### Route

- **Recent weakening + data/coverage anomaly** → `data-quality.md` first.
- **Recent weakening with stable data but horizon mismatch** → `two-year-sharpe.md` / `signal-design.md` under the current Target.
- **Edge concentrated in a narrow period or exact construction** → `overfitting.md` targeted controls.
- **Core thesis appears genuinely invalid and repair would require a new return source/dataset/region** → a scope boundary, not endless enhancement.

Do not use fixed ratios such as “recent Sharpe must exceed X% of earlier history.” The observed path only changes diagnostic priority.
